# Sample puzzles (fake)

Three made-up puzzles with placeholder images so tests, CI and local dev work without the
real puzzle data, which lives in a private repo. Same format as the real data:
`puzzles.json`, `images/`, `synonyms.json` (puzzle-specific synonym groups).

Point the code at the real puzzles with `PUZZLES_DIR=/path/to/prompt-guess-puzzles`, or check
that repo out next to this one as `prompt-guess-puzzles/` and it is picked up automatically.
